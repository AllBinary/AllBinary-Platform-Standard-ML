                             AllBinary Platform MLton (Standard ML)

What is it?

This repository contains code generated by the AllBinary Platform for support in MLton (Standard ML).  
This repo is used to allow developers to skip the MLton (Standard ML) code generation step.

What are some example games with this MLton (Standard ML) code?

https://allbinary.itch.io (The downloads with "-sml" in the filename are MLton (Standard ML) only builds. Currently that only includes nothing. Also the MLton (Standard ML) builds are not available on Google Play or other stores.)
